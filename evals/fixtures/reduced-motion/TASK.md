# Carousel (fixture)

A promotional carousel used on the marketing home page.

## What exists

- `web/src/components/Carousel.tsx` — renders the slides and advances them
  on a timer.
- `web/src/components/carousel.css` — the slide transition and a pulsing
  indicator animation.
- `web/src/styles/global.css` — site-wide styles.

## Notes

- Nothing in this workspace consults any user preference.
- There is no test runner and no browser here; the change is judged as
  written source.
